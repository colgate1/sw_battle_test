Review the implementation for:

- ownership
- lifetime
- RAII
- move semantics
- exception safety
- iterator invalidation
- undefined behaviour
- data races
- lock ordering
- thread safety
- API design
- performance
- unnecessary allocations
- cache locality
- readability
- maintainability

Classify findings:

Critical

Major

Minor

For every issue explain:

- why
- possible failure
- suggested improvement
